MPU-6050 motion sensor · fixing heat errors with machine learning · AI/ML for Mechanical Engineers, NIT Trichy

ThermoGyro

The same bike is used on a cool morning and after standing in the hot afternoon sun. Its motion sensor gives a small wrong reading that changes with temperature, so a bike that is standing still slowly "turns" in software. ThermoGyro learns this error from real lab recordings of three MPU-6050 chips and removes it.

Part 3 · calibrate your own sensor

Make a correction for your own MPU-6050

Every chip has its own error curve, so each sensor needs its own calibration. Record your board while it sits still and slowly warms up or cools down, then load the file here.

Your log file (CSV)

It needs five columns: time (s), temperature, gx, gy, gz. Common header names are recognised automatically.

A curve is fitted to each axis with the normal equation, W = (XᵀX)⁻¹XᵀY, just like in the report. When the board switches on, keep it still for a few seconds so it can measure its starting error; after that the curve corrects for temperature changes.
